# ITthute Fetch AudioVid v2.0.0-alpha16

Alpha16 improves the Download tab after successful media processing and makes yt-dlp troubleshooting more compact and useful.

## New

- **Share downloaded media** appears only after a media download has completed successfully, including yt-dlp post-processing.
- The large always-visible troubleshooting command block is replaced by a compact **Troubleshooting command** button.
- The troubleshooting popup displays the exact last generated yt-dlp command and provides **Copy command**, **Copy & open Termux**, and **Share command** actions.
- **Copy & open Termux** copies the command to Android's clipboard and opens Termux without automatically executing it, allowing the user to inspect, paste and run it manually.

## Retained

Alpha16 retains alpha15 Splitter folder browsing, dark-theme input contrast, clip lock/undo controls, post-download Media Library/Splitter/Converter shortcuts, temporary post-processing path repair, and Media Library request-token fixes.
