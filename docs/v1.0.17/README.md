# ITthute Fetch AudioVid v1.0.17 docs

This folder documents the v1.0.17 metadata-editing release.

Key files:

- `RELEASE-NOTES.md` — user-facing release summary.
- `FIX-REPORT.md` — implementation detail for the requested feature.
- `INSTALL.txt` — install and acceptance checks.
- `VERIFICATION.txt` — build and validation summary.
- `TEST-LOG.txt` — concise automated test log.
- `SHA256.txt` — checksums for generated public artifacts.
- `public-release-safety.md` — repository safety exclusions.

The live `main/update.json` is not changed by this documentation update. Update it only after the signed APK has been uploaded as a GitHub Release asset and the URL plus SHA-256 are verified.
