# v1.0.17 user-facing summary

Version 1.0.17 adds metadata editing to the Downloaded Media tab.

Open **Downloaded Media**, tap a file's `⋮` menu and select **Edit metadata**.

For music/audio files, you can edit title, artist, album, album artist, genre, year/date, track and comment.

For video files, you can edit title, creator/artist, genre, year/date and description/comment.

The genre field includes a chooser with common genres, but you can still type any genre manually.
