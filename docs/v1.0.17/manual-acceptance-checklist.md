# v1.0.17 manual acceptance checklist

1. Install v1.0.17 over v1.0.16.
2. Open the app and authenticate.
3. Run full setup verification.
4. Download or select an existing MP3 file in Downloaded Media.
5. Open the file menu and select **Edit metadata**.
6. Confirm audio fields appear: title, artist, album, album artist, genre, year/date, track and comment.
7. Select a genre from **Choose genre**.
8. Type a custom genre and save again.
9. Confirm the media file remains playable.
10. Repeat with an MP4 file and confirm video-appropriate fields appear.
11. Confirm Android media apps refresh after the save.
12. Generate diagnostics if FFmpeg reports a container-specific metadata write error.
