# v1.0.17 metadata field matrix

## Audio files

Editable fields:

| Field | FFmpeg metadata key |
|---|---|
| Title | `title` |
| Artist | `artist` |
| Album | `album` |
| Album artist | `album_artist` |
| Genre | `genre` |
| Year / date | `date` |
| Track number | `track` |
| Comment | `comment` |

## Video files

Editable fields:

| Field | FFmpeg metadata key |
|---|---|
| Title | `title` |
| Creator / artist | `artist` |
| Genre | `genre` |
| Year / date | `date` |
| Description / comment | `description` and `comment` |

## Genre picker

The genre field remains a normal editable text value. The chooser only pre-fills the field; users can type any custom genre.
