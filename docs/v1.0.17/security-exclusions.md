# v1.0.17 security exclusions

The following were not uploaded to the public repository:

- release keystore files;
- `.p12`, `.jks` or `.keystore` files;
- private signing bundles;
- signing credential text files;
- administrator plaintext password files;
- browser cookie files;
- copied diagnostic reports from the user's phone;
- downloaded media files.

Only public release documentation, update-manifest examples and source-change notes were merged.
